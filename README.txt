WHATSAPP WISHES:
Open script.js and replace:
groom: "919000000000"
bride: "919000000001"

Use the full country code without +, spaces or dashes.

Example:
groom: "919876543210"

The guest can select:
- Ramachandran G
- Monalisa B
- Both

Then their WhatsApp opens with the wish message.

EDIT WEDDING DETAILS:
In index.html replace:
YOUR WEDDING DATE
YOUR WEDDING TIME
Your Wedding Hall / Temple
Full Address, Tamil Nadu
and the Google Maps link.

GITHUB PAGES:
Upload all files to the repository root.
Settings → Pages → Deploy from branch → main → /(root).

The design is mobile-first and works as a static GitHub Pages website.
